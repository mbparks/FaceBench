Using the workbench

Shift-click layers to select several. Drag corners to resize; numeric inputs give exact values. Center guides snap dragged selections to either faceplate axis; hold Alt for free movement. In Inspector, Position, align & order aligns selected shapes and changes layer order. Shift-click selects several; the first selected shape can be a fixed reference. Groups move together. Arrow keys move 1 mm (Shift: 0.1). Delete removes selected layers. Ctrl/Cmd+Z undoes. Space temporarily pans in Design. 3D: drag to orbit, right-drag to pan, wheel to zoom.

Imported SVGs must contain closed paths/shapes. No scripts, linked resources, text nodes or clipping. Convert those to outlines first.

Export JSON to back up your work. 3MF preserves surface colors; assign printer materials in the slicer. Reports can be printed to PDF. Self-host all files in this folder; no build step.
